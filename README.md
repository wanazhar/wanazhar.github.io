# wanazhar.github.io

The source for [play.wanazhar.my](https://play.wanazhar.my): the store front and the
browser games it sells. Everything here is static and served by GitHub Pages from
this repository.

| Path | What it is | Source |
|---|---|---|
| `/` | the store front: landing page, search, cart | `index.html`, `assets/` |
| `/f1/` | Apex GP — arcade F1 championship, Three.js | `_f1-src/` |
| `/endlessrunner/` | Endless Runner | `_endlessrunner-src/` |
| `/kualalumpur/` | Kuala Lumpur | `_kualalumpur-src/` |
| `/emir/` | Emir's Car World | `_emir-src/` |
| `/spacebunnyalpha/` | Spacebunny Alpha | `_spacebunnyalpha-src/` |
| `/doom/` | DOOM Kawaii♡, authored in the published directory | `doom/` |

Design notes the games were built from are in `docs/plans/`. Each game's own notes live
with it: a `README.md` in every `_*-src/`, and `instruction.md` in `doom/`.

## Deploying

`.github/workflows/pages.yml` runs on every push to `main`. It installs, tests and
builds each `_*-src` project into the directory it publishes to, then uploads the
repository root as the Pages artifact. That is why most games' built output is
committed here alongside its source — and why `f1/` is not: it is generated by the
workflow, and a local build leaves it in the working tree only.
